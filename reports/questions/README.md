# 逐问报告目录

本目录用于存放每一问的独立 Markdown 报告。

## 文件命名

| 文件 | 用途 |
| --- | --- |
| `Q1_MODELING.md` | 问题一局部模型、推算过程和代码任务 |
| `Q2_MODELING.md` | 问题二局部模型、推算过程和代码任务 |
| `Q3_MODELING.md` | 问题三局部模型、推算过程和代码任务 |

按实际赛题问题数量增删文件，不要硬凑。

## 写作要求

- 各问共同遵循 [全局建模与数值求解注意事项](../GLOBAL_MODELING_NOTES.md)，明确继承项、新增假设和未完成检查，不把规则写成已验证结论。
- 所有逐问报告必须遵循 `../SYMBOL_STYLE_GUIDE.md`，同一对象在各问中不能换符号。
- 先复述这一问要解决什么。
- 再写已知条件、输出要求和关键歧义。
- 必须给出推算过程：变量如何定义、公式从哪里来、关键中间量如何得到。
- 最后给出代码任务、输出文件和校验方法。
- 数学表达统一使用 `$...$` 或 `$$...$$`。
- 等式统一用普通等号 `=`，不要用 `:=`。
- 优先使用直观符号；涉及对时间的变化率时，优先写成 `$\frac{d\theta(t)}{dt}$` 这类形式，不默认使用点号导数等简写。
- 公式要写成能渲染的完整表达，关系式必须有清楚的等号或不等号。
- 每一问开头只说明继承的全局符号和新增的局部符号，不要为同一对象重新起名。
- 每一问进入代码前，建议交给 `2-5model-audit` 做二次审稿；若审稿结论为 `REVISE`，先回修本问报告。
