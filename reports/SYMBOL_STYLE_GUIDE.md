# 本题符号表达规范

本文件用于固定当前题目的全局符号和推导表达风格。新建题目后，先在阶段2“主线总纲定稿”时填写本文件，再进入逐问推进。

## 1. 总原则

- 全题使用同一套全局符号；同一个对象不要在不同小问中换名。
- 先讲题意来源和物理含义，再写公式，最后说明如何计算或验证。
- 每一问的推算过程必须先于结论，不能只给最终公式或最终数值。
- 主推导优先使用题面量能直接对应的简单符号、坐标、表格字段和几何关系。
- 向量、矩阵、集合、路径函数等较抽象表达只在确有必要时使用，并应补充可读的坐标口径。
- 全局符号表只放高频符号；问题内临时符号在对应段落就地说明。
- 重要公式应编号，正文用“式(1)、式(2)”承接。

## 2. 全局符号表

在这里填写本题跨小问复用的符号。示例仅作占位，正式建模时按题面替换。

| 符号 | 含义 | 说明 |
| --- | --- | --- |
| $t$ | 时间或阶段编号 | 按题意确定单位 |
| $x_i,y_i$ | 第 $i$ 个对象的坐标或状态分量 | 若本题不是几何题，可替换为更贴近题面的状态量 |
| $v_i$ | 第 $i$ 个对象的速度、价值或评价量 | 按题意解释 |
| $l_i$ | 相邻对象距离、长度或连接量 | 按题意解释 |

## 3. 逐问继承规则

- `reports/questions/Q*_MODELING.md` 开头必须说明本问继承哪些全局符号。
- 若本问新增符号，只列本问真正需要的局部符号，不重复抄全局表。
- 若后续问题修正前问假设或符号，必须写明原因，并同步更新本文件。
- 若代码变量名和论文符号不同，应在“代码实现口径”中建立对应关系。

## 4. 自检清单

- 核心符号是否先定义后使用。
- 同一个对象是否全题只使用一个名字。
- 是否先解释公式来源，再给公式。
- 每一问是否包含清晰的 `STEP1 / STEP2 / STEP3` 或同等级推导结构。
- 重要公式是否有编号，正文是否能引用这些公式。
- 抽象符号是否没有抢占论文主推导。
